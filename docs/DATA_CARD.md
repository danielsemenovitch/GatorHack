# Below the Watermark benchmark: data card

## What it is

A labeled benchmark for detecting band level edits in western blot figures at publication resolution. Every forged image comes with a pixel mask marking exactly which pixels were changed.

| | |
|---|---|
| Images | 3,161 (964 clean, 2,197 forged) |
| Source panels | 241 blot panels |
| Source papers | 55 open access papers (CC BY), via Europe PMC |
| Split | by paper: 35 papers train (1,767 images), 20 papers test (1,394 images) |
| Median panel size | about 7,200 pixels (for example 160 × 45) |
| Forgery types | copy move, cross splice, AI splice, intensify, erase |
| Publishing steps | random chain of contrast, resize, JPEG (q70 to 95) or PDF round trip |

## How it was made

1. **Collection.** We queried Europe PMC for open access papers under a CC BY license (2017 to 2023) whose methods mention western blots or immunoblots, and downloaded up to two figures per paper whose captions mention a western blot. Figures are the web resolution versions served by Europe PMC, about 750 pixels wide, which is what most readers and reviewers actually see.
2. **Panels.** Blot panels were cut out automatically (solid non white rectangles that contain rows of band shaped blobs). Panels that were colorful, text heavy or too small were dropped. A small fraction of non blot panels (for example DNA gels or capillary "virtual blots") remain, and both are legitimate targets for the same fraud.
3. **Forgeries.** For each panel we generated two forgeries per method:
   - **copy move:** a band from another lane of the same blot, rescaled to fit
   - **cross splice:** a band from a different paper's blot (same split only)
   - **AI splice:** a band from a blot generated by Gemini's image tools
   - **intensify:** an existing band darkened and thickened in place
   - **erase:** a band removed by inpainting
   Most splices use darken only blending, so a pasted band only ever adds darkness on top of the membrane, like a real composite. About 15% use a hard rectangular paste as a crude baseline.
4. **Publishing.** Every image, clean or forged, then passes through a random chain: optional contrast change, optional resize (50 to 95%), then JPEG (quality 70 to 95), a PDF round trip, or PNG. Masks are resized with the image.

## Files

```
data/benchmark/images/<id>.png    the image
data/benchmark/masks/<id>.png     255 where pixels were changed, 0 elsewhere
data/benchmark/index.json         id, split, pmcid, panel, label, method, blend, publish steps, size
data/real_figures/metadata.json   source figure, PMCID, DOI, title, license, caption
```

Rebuild from scratch with `python -m scripts.build_benchmark --bundle <europe_pmc_bundle.json>`. The seed is fixed.

## Licensing and ethics

- Source figures are CC BY. Attribution for every figure (PMCID, DOI, title) is in `data/real_figures/metadata.json`. Forged images are derivatives we made. **None of the forgeries reflect anything the original authors did.** Their published figures are unaltered.
- The AI donor blots were generated by us with Gemini.
- No unpublished or private lab data is included.

## Known limitations

- Web resolution figures: many bands are only around 13 × 6 pixels, which makes noise based forensics very hard. That is deliberate, since it matches what reviewers see, but results will differ on full resolution originals.
- Forgeries are generated, not collected from real misconduct cases. A real forger may use tools or care we did not simulate.
- The AI donor pool is small (two Gemini blots, cut into many bands). The held out method experiment in the results tests whether a detector generalizes to AI splices it never saw.
- Automatic panel extraction is imperfect.
